# spring-shopping-precourse

## 구현할 기능 목록

### 상품

- [ ] 상품을 생성한다. (`POST /api/products`)
- [ ] 특정 상품을 조회한다. (`GET /api/products/{productId}`)
- [ ] 모든 상품의 목록을 조회한다. (`GET /api/products`)
- [ ] 기존 상품의 정보를 수정한다. (`PUT /api/products/{productId}`)
- [ ] 특정 상품을 삭제한다. (`DELETE /api/products/{productId}`)
- [ ] 상품은 이름, 가격, 이미지 URL을 가진다.
- [ ] 상품 이미지는 파일 업로드 없이 URL로 입력받는다.
- [ ] 존재하지 않는 상품을 조회·수정·삭제하면 오류 응답을 반환한다.

### 상품 유효성 검사

- [ ] 상품 이름은 비어 있을 수 없다.
- [ ] 상품 이름은 공백을 포함해 최대 15자까지 입력할 수 있다.
- [ ] 상품 이름에는 `( )`, `[ ]`, `+`, `-`, `&`, `/`, `_` 외의 특수 문자를 사용할 수 없다.
- [ ] 상품 이름에 비속어가 포함되어 있는지 PurgoMalum API로 검사한다.
- [ ] 상품 가격은 0 이상이어야 한다.
- [ ] 상품 이미지 URL은 비어 있을 수 없다.
- [ ] 상품을 생성하거나 수정할 때 값이 잘못되면 오류 메시지가 담긴 오류 응답을 반환한다.

### 회원

- [ ] 이메일과 비밀번호로 회원 가입을 하고 토큰을 받는다. (`POST /api/members/register`)
- [ ] 이메일과 비밀번호로 로그인하고 토큰을 받는다. (`POST /api/members/login`)
- [ ] 이메일과 비밀번호는 비어 있을 수 없고, 이메일은 올바른 형식이어야 한다.
- [ ] 이미 가입된 이메일로는 가입할 수 없다.
- [ ] 이메일이 존재하지 않거나 비밀번호가 일치하지 않으면 로그인에 실패한다.
- [ ] 회원 인증 토큰을 생성한다.
- [ ] 요청 헤더의 토큰을 검증해 인증된 회원을 확인한다.
- [ ] 토큰이 없거나 올바르지 않으면 인증 오류 응답을 반환한다.

### 위시 리스트

- [ ] 인증된 회원의 위시 리스트에 상품을 추가한다. (`POST /api/wishes`)
- [ ] 인증된 회원의 위시 리스트에 있는 상품 목록을 조회한다. (`GET /api/wishes`)
- [ ] 인증된 회원의 위시 리스트에서 상품을 삭제한다. (`DELETE /api/wishes/{wishId}`)
- [ ] 존재하지 않는 상품은 위시 리스트에 추가할 수 없다.
- [ ] 이미 위시 리스트에 있는 상품은 중복으로 추가할 수 없다.
- [ ] 다른 회원의 위시 리스트 항목은 삭제할 수 없다.

### 예외 처리

- [ ] 모든 오류 응답은 JSON 형식으로 반환한다.

## 기능 목록

회원이 상품을 조회한다.

'상품에는 이름, 가격, 이미지 URL이 포함된다.'

- 상품
    - 이름
    - 가격
    - 이미지 URL
- 상품 이름은 공백을 포함하여 최대 15자까지 입력할 수 있다.
    - '(), [], +, -, &, /, _' 가 아니면 예외 발생.
    - 공백만 있어도 안됨.
    - 비속어가 포함될 수 없다. -> 이것은 다른 레이어에서 해야겟다.


'회원은 이메일과 비밀번호로 가입할 수 있다.'

- 회원은 이메일과 비밀번호를 고유하게 가진다. 
  - 이메일의 localPart 도 공백이면, 안되고 어떤 규칙이 있겠지만, 일단 무시한다. 
    - 원래는 객체 자체가 비밀번호를 그대로 가지고 있지는 않지만, 그 부분은 일단 무시하자.
      
    - 이메일
      - localPart 와 domain (tom@gmail.com)기
      - 회원들 고유한 단일의 이메일을 가진다고 가정한다.
    - 비밀번호
      - 10자 이상이어야 함.
      - 그 외의 특수문자 등등 생략.
      - 무언가, 비밀번호가 내부적으로 암호화된 상태로 되어 있고, 암/복호화하는 것이 있겠다. 
      - 일단 인터페이스로 하고 PlainPasswordHashing 으로 해보자.

'가입, 로그인'

- 가입
  - 가입 시, Member 객체 생성한다.
  - 편리성을 위한 Id 도 생성.  

- 로그인
  - 로그인 시, 비밀

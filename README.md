# spring-shopping-precourse

## Goal
HTTP API 구현
- HTTP 요청과 응답은 JSON 형식으로 주고 받으며, 스프링 프레임워크를 사용한 웹 애플리케이션


### 상품
- 상품 조회,추가,수정,삭제 기능 구현
[x] 상품에는 이름,가격,이미지 URL 포함
[x] 상품 이미지는 파일 업로드가 아닌 URL 입력 방식으로 관리

### 유효성 검사 및 예외 처리
- 상품을 추가 or 수정 할 때, 클라이언트로부터 전달된 값 유효성 검사 실시
  - 유효성 검사가 잘못 된 경우 적절한 오류 응답을 반환
[x] 상품 이름은 공백 포함 최대 15자
[x] 상품 이름에 가능한 특수문자: (),[],+,-,&,/,_
  - 그 외 특수 문자 불가능
  - 공백뿐인 이름 불가능
  - 상품 이름이 비어있으면 안 됨
[x] 상품 이름에는 비속어가 포함되면 안 됨
  [x] PurgoMalum API를 호출하여 비속어 포함 여부를 검사

### 회원 로그인
회원가입과 로그인을 통해 사용자 인증 기능을 구현
[x] 회원은 이메일과 비밀번호로 가입 가능
[x] 로그인 시 이베일과 비밀번호 검증
  [x] 일치할 시 인증 토큰 발급
- 토큰 생성 방식은 자유롭게 선택
  - 회원가입,로그인 성공 시 UUID v4 토큰을 발급하고 서버 메모리에 토큰과 회원 이메일의 매핑을 저장

### 위시 리스트
- 인증된 사용자를 대상으로 위시 리스트 기능 구현
[x] 위시 리스트에 등록된 상품 목록 조회
[x] 위시 리스트에 상품 추가 가능
[x] 위시 리스트에서 상품 삭제 가능

## 구현 전략
- 삼품 관리: 빈 목록을 조회하는것 부터 만든 뒤 서버가 JSON으로 응답하지는 확인. 등록,수정,삭제를 하나씩 추가하고 매번 목록을 다시 조회하여 결과 확인
- 상품명 검사: 등록할 때와 수정할 때 같은 규칙ㄷ을 사용하도록 검사 코드를 한 곳에 모음. 이름은 저장하기 전에 검사하고 '머그컵'을 '머그컵!'으로 바꾸려는 요청이 들어오면 원래 이름이 그대로 남도록 함
- 회원 인증과 위시리스트: 누가 찜했는지 알아야하므로 회원가입과 로그인을 먼저 구현. 로그인 토큰으로 회원을 찾아 각자의 찜 목록을 관리.

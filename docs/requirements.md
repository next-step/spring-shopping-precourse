# 기능 요구사항

온라인 쇼핑몰을 위한 간단한 HTTP API를 구현한다.
HTTP 요청과 응답은 JSON 형식으로 주고받으며, 스프링 프레임워크를 사용하여 웹 애플리케이션으로 구현한다.

## 1. 상품

상품을 조회, 추가, 수정, 삭제하는 기능을 구현한다.

- [ ] 상품을 조회할 수 있다.
- [ ] 상품을 추가할 수 있다.
- [ ] 상품을 수정할 수 있다.
- [ ] 상품을 삭제할 수 있다.
- [ ] 상품에는 이름, 가격, 이미지 URL이 포함된다.
- [ ] 상품 이미지는 파일 업로드가 아닌 URL 입력 방식으로 관리한다.

## 2. 유효성 검사 및 예외 처리

상품을 추가하거나 수정할 때, 클라이언트로부터 전달된 값의 유효성을 검사하고 잘못된 경우 적절한 오류 응답을 반환한다.

- [ ] 상품 이름은 공백을 포함하여 최대 15자까지 입력할 수 있다.
- [ ] 상품 이름에는 아래 특수 문자만 사용할 수 있다.
  - 가능: `( )`, `[ ]`, `+`, `-`, `&`, `/`, `_`
  - 그 외 특수 문자는 사용할 수 없다.
- [ ] 상품 이름에는 비속어가 포함될 수 없다.
  - [PurgoMalum](https://www.purgomalum.com/) API를 호출하여 비속어 포함 여부를 검사한다.

## 3. 회원 로그인

회원 가입과 로그인을 통해 사용자 인증 기능을 구현한다.

- [ ] 회원은 이메일과 비밀번호로 가입할 수 있다.
  - [ ] 이메일 형식을 검사한다.
  - [ ] 이메일은 대소문자를 구분하지 않는다.
  - [ ] 비밀번호는 최소 8자리 이상이어야 한다.
- [ ] 로그인 시 이메일과 비밀번호를 검증하고, 일치하면 인증 토큰을 발급한다.
- [ ] 토큰 생성 방식은 자유롭게 선택한다.

## 4. 위시 리스트

인증된 사용자를 대상으로 위시 리스트 기능을 구현한다.

- [ ] 위시 리스트에 등록된 상품 목록을 조회할 수 있다.
- [ ] 위시 리스트에 상품을 추가할 수 있다.
- [ ] 위시 리스트에서 상품을 삭제할 수 있다.
